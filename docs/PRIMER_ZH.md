## 1. 任务：带规则掩码的矩阵补全

把所有物理细节先扔掉。我们要做的事情是这样的：

有一个矩阵 `U`，形状 `(n_freq, n_sensor)`。你可以完全当它是一张单通道图像
（只不过每个像素是复数）。

- **列** = 一个传感器的位置。传感器排成一条等间距的直线。
- **行** = 一个频率。这些行是把每个传感器记录的那段时间信号做 FFT 得到的。
- **我们只观测到每隔 5 列中的 1 列**（14 / 70），其余 56 列完全看不到。
- **任务**：把看不到的 56 列补出来。

在 ML 里这就是**带固定 stride 掩码的 inpainting**，或者说**沿一个轴的
super-resolution**。掩码是规则的、已知的、不随机。

这个 setting 和 NeRF / INR / 神经算子从稀疏观测重建连续场是同一件事，
只是被剥到了最小。

### 为什么不是随机掩码

随机掩码下这个问题会变成压缩感知，结论完全不同（稀疏的高频内容可以被恢复）。
规则阵列既是本文结论成立的前提，也更贴近真实传感硬件——检波器、麦克风阵列、
相机像素都是等间距的。

## 2. 核心直觉：混叠、剪切、以及为什么换坐标有用

### 2.1 混叠 = 马车轮效应

老电影里马车轮看起来在倒转，是因为帧率不够：轮辐转过的角度太大，采样后无法
区分"快速正转"和"慢速倒转"。这就是**混叠**（aliasing）。

同样的事发生在空间上。沿传感器方向变化太快的成分，在稀疏阵列上会和某个变化很慢的
成分**完全重合**——采样之后两者一模一样，任何算法都分不开。

区分得开与分不开的分界线叫 **Nyquist**：间距为 `m` 的阵列，空间上每 `2m` 个单位
振荡一次是极限，比这更快的一律混叠。

### 2.2 一个脉冲在图像里是一条斜线

想象一个脉冲沿测线传播。传感器 `x` 在时刻 `x / c` 收到它（`c` 是传播速度）。
把 `(时间 × 传感器)` 画成图像，这个脉冲就是一条**斜线**，斜率 `1/c`。

现在只看每隔 5 列。**一条很陡的斜线，和一条缓缓反向倾斜的斜线，采样后看起来一样**
——这就是马车轮效应在这张图上的样子。所以陡的斜线是不可辨识的。

### 2.3 换坐标 = 把斜线扳正

如果你把第 `x` 列整体**上移 `x / c`**，那条斜线就变成了竖直的。
而竖直意味着**沿传感器方向完全不变**——这时候任何一列都决定了所有列。

<pre>
   原坐标                        换坐标后
   ┌──────────────┐             ┌──────────────┐
 时│ ╲            │             │ │            │
 间│   ╲          │   un-shear  │ │            │
   │     ╲        │  ─────────► │ │            │
   │       ╲      │             │ │            │
   └──────────────┘             └──────────────┘
      传感器 →                     传感器 →
   斜率高 → 混叠 → 不可辨识        沿传感器不变 → 一列就够
</pre>

**这个操作不增加任何数据、不增加任何参数。** 它只是换了一个记账方式，
而门槛（Nyquist）的位置由传感器密度决定，不动。所以能量被搬到了门槛的另一侧。

在实现上，"上移 `τ(x)`" 在频域就是给第 `x` 列乘一个复数
`exp(+2πi·f·τ(x))`——每个位置一个延迟，仅此而已。

### 2.4 真实的场不是一条斜线

真实的波场是很多条斜线的叠加（直达波、各种反射、散射），而且斜率随位置变化
（介质不均匀）。所以"扳正"不是一个全局操作，而是一个**每个传感器一个延迟**的
光滑函数 `τ(x)`。**这个函数就是本项目要学的东西。**

## 3. 名词表

| 名词 | 在这里是什么意思 | ML 里最接近的东西 |
|---|---|---|
| **场（field）** | 一个定义在空间和时间上的物理量，比如声压、速度 | 一个连续函数，你只在离散点上观测到它 |
| **传感器阵列** | 等间距排成一条线的测量点 | 规则采样网格 |
| **波数（wavenumber）** | 空间方向上的"频率"：每单位距离振荡几次 | 沿某个轴做 FFT 后的频率变量 |
| **Nyquist** | 采样能分辨的最高波数，`1/(2m)` | 采样定理的分辨极限 |
| **混叠（aliasing）** | 高于 Nyquist 的成分被误认为某个低频成分 | 马车轮效应；下采样时的走样 |
| **可辨识性界（bound）** | **任何**估计器误差的下界，由采样丢掉的能量决定 | **贝叶斯误差的类比**——只不过来源是采样而不是标签噪声 |
| **估计器松弛** | 实测误差 − 界 | 超额风险（excess risk） |
| **坐标变换 / warp** | 每个传感器一个时间平移 `τ(x)` | 输入域的重参数化；等价于给图像反剪切 |
| **载波（carrier）** | 上述平移在频域的形式 `exp(2πi f τ(x))` | 一个逐元素的复数乘子 |
| **带限估计器** | 只用采样能表示的那些波数做最小二乘拟合 | **零参数**的最优线性重构；不存在欠拟合 |
| **谱泄漏 / 窗函数** | 非周期信号做 FFT 会产生虚假高频；加窗消除它 | 类似做 FFT 前先乘一个平滑遮罩 |
| **摊销（amortisation）** | 训一个网络，对新实例一次前向给出答案 | 就是 ML 里的 amortised inference |
| **炮集（shot gather）** | 放一次炮，一排接收器记录到的 `(时间 × 接收器)` 矩阵 | 一张灰度图 |
| **动校正（moveout）** | 到达时间随接收器距离变化的形状；地震里是**双曲线** | 那条要被扳正的曲线，不是直线 |
| **PIV** | 用相机测量流体速度场，输出规则网格上的向量场 | 真实测量的、网格化的 2D 向量场视频 |

## 4. 四个数据集分别是什么

全部公开，**无一由本项目生成**。选它们是因为它们在"是否具有相干输运结构"这条轴上
分布得很开——判据应该能把它们分开。

| 数据 | 物理上是什么 | 数据长什么样 | 预期 |
|---|---|---|---|
| **OpenFWI CurveFault-A** | 地震勘探：地下放炮，地面测线接收 | 500 个地下速度模型 × 5 炮 × (1000 时间 × 70 接收器) | 强输运（波传播），应有大收益 |
| **RealPDEBench cylinder（real）** | **真实实验测量**的圆柱绕流尾迹，PIV 拍摄 | 92 个工况，(3990 帧 × 64 × 128)，200 Hz，雷诺数 2500–11700 | 中等输运（涡被对流带走） |
| **Kuramoto–Sivashinsky** | 一维混沌 PDE，有行波但混沌 | 128 条轨迹 × (129 步 × 64 空间点) | 弱输运 |
| **Kolmogorov 2D NS** | 二维强迫湍流，两个雷诺数 | 200 / 100 条轨迹 × (501 步 × 64² / 128²) | **无相干输运**，负对照 |

真实测量那一份特别重要：本项目此前所有大收益都出自我们自己写的求解器，
而 PIV 数据是相机拍出来的，无法被求解器的假设污染。

## 5. 为什么 AI 社区应该在意

坐标变换不是波场特有的东西。下面这些方法的共同内核都是它：

| 方法 | 它其实是什么坐标变换 |
|---|---|
| Fourier features / 位置编码 | **固定的**坐标变换 |
| Deformable / dynamic NeRF 的形变场 | **学出来的**坐标变换 |
| 视频的运动补偿、连拍对齐 | 按运动做的时空 warp |
| Canonicalization / 等变学习 | 把实例映到标准坐标 |

这些方法都在改坐标，但**没有一个训练前可算的量回答"值不值得、最多能买到多少"**。
默认的应对方式是加容量、换编码、调超参。

本项目给的就是那个量。它免标签、与模型无关、一次 FFT 可算，
并且在做变换**之前**就预测出变换的收益（R² 0.9915）。
