# 定位：可辨识性，而不是容量

本文件确定论文的叙事主线与核心实验，其他一切服从它。写于 2026-08-20，
在 `exp01`–`exp20` 的证据基础上。

## 1. 一句话

> 稀疏波场重构的瓶颈是**可辨识性**，不是模型容量。传感器之间的场在信息上无法被
> 采样确定；物理先验的作用不是"更好的归纳偏置"，而是**把缺失的自由度补进来**。
> 缺多少、补得够不够、什么时候根本补不上——都可以在训练前用一个可计算的量算出来，
> 而这些信息有时可以自监督地从数据本身学回来。

## 2. 为什么是这个故事，而不是另外两个

考虑过的备选：

- **"更好的重构"**：我们确有 13.6× 的传感器效率和 9.8–11.5× 的等预算压缩，
  但它们集中在一个区间，且最大的数字来自自建求解器。作为主线会被"公开数据上呢"
  一击即溃。
- **"更好的泛化"**：**目前没有证据支持**。跨频外推是负结果（§10），
  跨介质/跨几何迁移尚未测试。不能讲。

选择"可辨识性"是因为它是唯一能把**全部**结果——包括所有负结果——统一起来的框架：
负结果不再是"方法失效"，而是"被预测到的不可辨识"。

## 3. 支撑证据（已有）

| 证据 | 它在故事里的角色 |
|---|---|
| 网络训练误差 0.000、测试误差 1.0；加载波（不增加任何数据）即解开（`exp14`） | 失败不是容量问题 |
| `rank ≈ B·Λ`，合成 R²=0.998、FDTD 0.944、maze 0.954（`exp01`–`exp03`） | 缺失自由度是可计算的 |
| 载波容限 `δτ < 1/B`；粗糙误差致命、平滑误差无害（`exp07`） | 补进来的信息有精确门槛 |
| 自监督学出的坐标追平物理、修复错物理、色散时超过 1.74×（`exp17`/`exp18`） | 缺的信息有时能从数据学回 |
| 四个公开基准三个落在必然无效区间，事前预测全中（`exp06`/`exp20`） | 判据在真实数据上先说后验 |
| shifted POD 在每个波场上都没赢过 plain POD（`exp16`） | 不是任意坐标变换都补信息 |

## 4. 还缺的一块（核心实验）

上面全是**点状**证据。故事要成立，需要把它们连成一条**采样复杂度标度律**：

> 达到给定精度所需的传感器数 `N ∝ B·Λ`，
> 且**原始坐标与对齐坐标的点落在同一条线上**——坐标变换不改变定律，
> 只改变你落在线上的哪个位置。

这是论文的主图，也是把"可辨识性"从比喻变成度量的一步。

## 5. 实验设计（保持简洁，只有四项）

- **E1 可辨识性界（核心）** ✅ `exp21`、`exp23`。最初设想的是"所需传感器数 ∝ B·Λ"，
  但传感任务的支配量是它的**空间对偶**：规则阵列 Nyquist 波数之上的能量。
  458 组测量，打破比例 1.7%（自建+时域公开）与 8.0%（频域公开），R²=0.80/0.88。
  换算成传感器数量：open/clear 省 **24×**，其余区间无收益。
- **E2 不是容量** ✅ `exp22`。128 倍参数量跨度上测试误差只动 3%，训练误差恒为 10⁻⁷；
  零参数的线性插值打败每一个网络。换坐标系把界从 0.766 降到 0.527，所有估计器跟着降。
- **E3 信息从哪来** ✅ `exp24`。**把界本身当损失函数**：纯学习在界上追平物理
  （0.528 vs 0.533），并把被破坏的载波修回（0.931 → 0.521）。目标必须与指标一致——
  改用频率轴目标只到 0.644。
- **E4 事前预测审计** ✅ `exp06`、`exp20`、`exp19`。四个公开波动基准中三个落在
  必然无效区间，判据事前预测全中。

- **E5 留出验证（追加）** ✅ `exp25`。整套流程冻结，12 个从未使用的 seed、252 组测量：
  三条主张全部复现（界打破 4.8% / 网络 0.0%；网络 0.995 vs 线性 0.759；
  纯学习 0.554 vs 物理 0.552）。
- **E6 摊销与跨介质迁移（追加）** ✅ `exp26`。把坐标从"逐场拟合"升级为"介质→坐标的规则"：
  仅以界为损失、无标签，在未见介质上一次前向传播即追平物理（0.589 vs 0.581），
  在另一介质族上超过物理（0.300 vs 0.330），**跨介质族**持平（0.364 vs 0.364）。
  seed 标准差 ≤ 0.001。物理热启动在摊销设定下不再必要。

### 测量纪律（三条都是踩坑后加的，写进论文方法节）

1. 规则阵列而非随机采样——随机采样下混叠不是墙，该量不再是界；
2. 有遮挡的区域要裁剪不能补零——补零凭空制造高波数能量；
3. 加锥形窗且预测与实测同窗——否则泄漏拖尾本身就超过被下界的误差。

## 6. 不做的事

- 不追求重构 SOTA，不与 neural operator 正面比较；
- 不声称跨频泛化或跨介质迁移（没有证据）；
- 不声称对定常流场适用（`exp19` 已证否）。
