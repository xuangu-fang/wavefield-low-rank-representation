# 定位：可辨识性，而不是容量

本文件确定论文的叙事主线与核心实验，其他一切服从它。写于 2026-08-20，
在 `exp01`–`exp20` 的证据基础上。

## 1. 一句话

> 稀疏波场重构的瓶颈是**可辨识性**，不是模型容量。传感器之间的场在信息上无法被
> 采样确定；物理先验的作用不是"更好的归纳偏置"，而是**把缺失的自由度补进来**。
> 缺多少、补得够不够、什么时候根本补不上——都可以在训练前用一个可计算的量算出来，
> 而这些信息有时可以自监督地从数据本身学回来。

## 2. 为什么是这个故事，而不是另外两个

考虑过的备选：

- **"更好的重构"**：我们确有 13.6× 的传感器效率和 9.8–11.5× 的等预算压缩，
  但它们集中在一个区间，且最大的数字来自自建求解器。作为主线会被"公开数据上呢"
  一击即溃。
- **"更好的泛化"**：**目前没有证据支持**。跨频外推是负结果（§10），
  跨介质/跨几何迁移尚未测试。不能讲。

选择"可辨识性"是因为它是唯一能把**全部**结果——包括所有负结果——统一起来的框架：
负结果不再是"方法失效"，而是"被预测到的不可辨识"。

## 3. 支撑证据（已有）

| 证据 | 它在故事里的角色 |
|---|---|
| 网络训练误差 0.000、测试误差 1.0；加载波（不增加任何数据）即解开（`exp14`） | 失败不是容量问题 |
| `rank ≈ B·Λ`，合成 R²=0.998、FDTD 0.944、maze 0.954（`exp01`–`exp03`） | 缺失自由度是可计算的 |
| 载波容限 `δτ < 1/B`；粗糙误差致命、平滑误差无害（`exp07`） | 补进来的信息有精确门槛 |
| 自监督学出的坐标追平物理、修复错物理、色散时超过 1.74×（`exp17`/`exp18`） | 缺的信息有时能从数据学回 |
| 四个公开基准三个落在必然无效区间，事前预测全中（`exp06`/`exp20`） | 判据在真实数据上先说后验 |
| shifted POD 在每个波场上都没赢过 plain POD（`exp16`） | 不是任意坐标变换都补信息 |

## 4. 还缺的一块（核心实验）

上面全是**点状**证据。故事要成立，需要把它们连成一条**采样复杂度标度律**：

> 达到给定精度所需的传感器数 `N ∝ B·Λ`，
> 且**原始坐标与对齐坐标的点落在同一条线上**——坐标变换不改变定律，
> 只改变你落在线上的哪个位置。

这是论文的主图，也是把"可辨识性"从比喻变成度量的一步。

## 5. 实验设计（保持简洁，只有四项）

- **E1 采样复杂度标度律（核心）**：固定目标精度，测所需传感器数 vs `B·Λ`，
  跨全部区间、两种坐标系、波动与非波动。预测斜率 ≈ 1，两种坐标系共线。
- **E2 不是容量**：在固定传感器数下扫模型容量与训练量，证明测试误差对容量**平坦**
  而训练误差趋零；同一预算下一个**线性**方法在对齐坐标里却能解开。
- **E3 信息从哪来**：物理 / 学习 / 二者，已有 `exp17`、`exp18`，按主线重写呈现。
- **E4 事前预测审计**：把判据的事前预测扩展到更多公开数据集，报告命中率。

## 6. 不做的事

- 不追求重构 SOTA，不与 neural operator 正面比较；
- 不声称跨频泛化或跨介质迁移（没有证据）；
- 不声称对定常流场适用（`exp19` 已证否）。
